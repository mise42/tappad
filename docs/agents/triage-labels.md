# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  |
| -------------------------- | -------------------- | ---------------------------------------- |
| `needs-triage`             | `intake: needs-review` | Product intake needs review for user value, buyer fit, scope, and timing |
| `needs-info`               | `intake: needs-context` | Waiting for missing user scenario, acceptance criteria, pricing/entitlement impact, or reproduction detail |
| `ready-for-agent`          | `execution: agent-ready` | Fully specified and safe for an AFK agent to implement or investigate |
| `ready-for-human`          | `execution: human-needed` | Requires human product judgment, design choice, external account access, release authority, or high-risk implementation |
| `wontfix`                  | `decision: not-now` | Not in the current commercial direction or roadmap window |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.

Edit the right-hand column to match whatever vocabulary you actually use.
